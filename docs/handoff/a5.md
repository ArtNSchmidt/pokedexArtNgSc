# Handoff A5 — Shell web e design system

## O que entreguei

`apps/web/` — a casca do app, sem nenhuma tela do produto:

- `index.html` (Poppins via Google Fonts com `display=swap`, `viewport`, `theme-color`), `public/favicon.svg`.
- `src/styles/tokens.css`: tokens transcritos do style guide da Figma (ADR-007) — identidade `#DC0A2D`, cinzas, **18 cores de tipo** (`--type-fire`…) e a cor de texto de cada uma (`--type-fire-ink`…), tipografia Poppins com piso de 12 px, espaçamento base 4 px, raios, elevações dp2/dp6/inner, alvo de toque 44 px.
- `src/styles/global.css`: reset, `color-scheme: light`, utilitários tipográficos (`.t-headline`, `.t-subtitle-1`…), `.visually-hidden`, `prefers-reduced-motion`.
- `src/shared/ui/`: `Card`, `Badge`, `Button` + `IconLink`, `SearchInput`, `Select`, `Skeleton`, `Spinner`, `EmptyState`, `ErrorState` (com "Tentar de novo"), `StatBar`, `Pagination`, `Popover`, `icons` (10 SVG inline), `cx`. Todos sem estado de servidor, controlados por props, CSS Modules.
- `src/shared/format.ts`: `formatPokedexNumber` (`#006`), `formatMeters` (`0,7 m`), `formatKilograms`, `formatStatValue` (`045`), `formatMultiplier` (`×4`, `×½`, `imune`), `orPlaceholder` (`null` → `—`), `formatGeneration`, `humanizeSlug`.
- `src/shared/api/client.ts`: `apiGet(path, schema, { signal, fetchFn })` valida a resposta com o schema do A1; `ApiClientError` (código + status de §6.3), `ApiContractError`, `describeError`, `isNotFoundError`, `isRetryableError`.
- `src/shared/api/queries.ts`: `pokemonListQuery(params)` (`keepPreviousData`), `pokemonDetailQuery(idOrName)`, `typesQuery`, `generationsQuery`, `queryKeys`, `STALE_TIME_MS` (5 min), `toListSearchParams`.
- `src/app/`: `providers.tsx` (`AppProviders`, `createQueryClient` com retry só para falhas ≥ 500), `router.tsx` (`createAppRouter(pages)`, `createAppRoutes`, `paths`), `AppLayout.tsx`, `NotFoundPage.tsx`, `RouteErrorPage.tsx`, **`CatalogPage.tsx` (temporária)**.
- `src/main.tsx`: composition root do frontend. Hoje monta `CatalogPage` nas duas rotas.
- Testes: `client.test.ts` (5), `Pagination.test.tsx` (2), `ErrorState.test.tsx` (1).

## Decisões que tomei e a alternativa que descartei

| Decisão                                                                                                                                                        | Alternativa descartada e por quê                                                                                                                |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| **Cor de texto por tipo** (`--type-*-ink`): branco só onde alcança ≥ 3:1 (fighting, poison, ghost, water, psychic, dragon, dark); os demais usam `--gray-dark` | Branco em todos, como na Figma: `electric` com branco fica em 1,5:1 — ilegível. Fidelidade visual não vale um chip que não se lê.               |
| Piso de **12 px** no corpo (Figma: 10 px/8 px), mesma hierarquia                                                                                               | Copiar 10 px/8 px: abaixo do mínimo legível em web; a hierarquia (headline 24 › subtitle 14/12 › body 12 › caption 10) se mantém.               |
| **`createAppRouter(pages)`**: o shell recebe as telas por parâmetro                                                                                            | Importar `features/` do `router.tsx`: o typecheck do A5 falharia até o A6 existir, e o shell passaria a depender das telas (seta invertida).    |
| `apiGet` recebe uma **porta estreita de `fetch`** (`FetchLike`: `ok`, `status`, `json`)                                                                        | Tipar como `typeof fetch`: os testes precisariam construir `Response` inteiros ou usar cast.                                                    |
| `retry` só para erros ≥ 500 e falhas de rede                                                                                                                   | `retry: 1` global: 404 e 400 seriam repetidos sem chance de sucesso.                                                                            |
| `Button` recebe `ref` como prop comum (`ComponentProps<'button'>`, React 19)                                                                                   | `forwardRef`: legado no React 19.                                                                                                               |
| Área de toque de 44 px via `::before` em volta do visual de 32 px                                                                                              | Aumentar o círculo para 44 px: quebraria a proporção da Figma.                                                                                  |
| Prints com **Playwright CLI + Edge instalado** (`--channel=msedge`), sem adicionar dependência                                                                 | `msedge --headless --window-size=360,…`: o Edge impõe largura mínima de janela (~500 px) e o layout saía diagramado a 490 px, recortado em 360. |
| `Select` nativo estilizado                                                                                                                                     | Dropdown custom: teclado, toque e leitor de tela de graça com o nativo; o visual da Figma é só a moldura.                                       |

## Pendências e riscos conhecidos

- **`CatalogPage.tsx` é temporária** e está montada nas duas rotas em `main.tsx`; deve ser removida
  na integração final (§7.7), quando `main.tsx` passar a receber as telas do A6.
- Poppins depende de rede; `display=swap` e o fallback de sistema mantêm o layout sem ela.
- O `Popover` não tem _focus trap_: fecha com Escape e clique fora, suficiente para dois `Select`.
