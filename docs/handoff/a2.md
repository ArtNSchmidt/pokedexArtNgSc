# Handoff A2 — Domínio (funções puras)

## O que entreguei

`packages/domain/src/` com as regras de negócio do projeto em funções puras, as portas
(ADR-002/006) e os erros tipados (§5.3). Nenhum `import` de `fastify`, `react`, `node:http`,
`fetch` ou `zod` em runtime; os testes rodam offline sobre dados gravados da API real.

## Decisões que tomei e a alternativa que descartei

| Decisão                                                                                                                                                              | Alternativa descartada e por quê                                                                                                                                                                                                    |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Entradas no formato do domínio** (`DamageRelations`, `EvolutionChainNode`), não o JSON da PokéAPI                                                                  | Receber o DTO cru: o domínio passaria a conhecer `double_damage_from` e `evolves_to`, e uma mudança no upstream quebraria a regra em vez do adapter (ADR-005/006).                                                                  |
| **Deduplicação de condições de evolução** após projeção nos 7 campos do contrato                                                                                     | Um passo por entrada literal (Anexo B ao pé da letra): Eevee daria 19 passos (Leafeon e Glaceon têm 6 entradas cada, só diferentes em `location`). O teste de §7.4 ("8 passos") vira "8 destinos distintos", que é a garantia útil. |
| `calculateWeaknesses` **satura** o produto em ×4 / ×¼ em vez de lançar                                                                                               | Lançar por entrada inválida viola §5.3; com ≤ 2 tipos o clamp nunca atua.                                                                                                                                                           |
| `sanitizeFlavorText` devolve `null` também para texto que fica vazio                                                                                                 | Devolver `""`: a UI teria dois "sem texto" diferentes para tratar.                                                                                                                                                                  |
| `selectLocalizedText` genérica (idioma + texto) em vez de três funções                                                                                               | `pickFlavorText`, `pickGenus`, `pickShortEffect`: mesma regra, três cópias.                                                                                                                                                         |
| `searchByName` e `paginate` no domínio, não no índice do A3                                                                                                          | Deixá-las em `pokemonIndex.ts`: a ordenação "começa com antes de contém" é regra de produto e merece teste sem infraestrutura.                                                                                                      |
| Fixtures `__fixtures__/typeRelations.ts` e `evolutionChains.ts` **geradas** dos JSON reais (`/type/{name}` × 18, `/evolution-chain/{1,7,67}`) e excluídas do `dist/` | Transcrever à mão: 18 × 3 listas de tipos é onde o erro de digitação vira "teste que passa com gabarito errado".                                                                                                                    |

## Pendências e riscos conhecidos

- Nenhuma função aqui conhece HTTP; qualquer necessidade de rede num teste indica erro de camada.
- O clamp de `toDamageMultiplier` é código defensivo que a Pokédex não exercita (contrato limita a
  2 tipos); está documentado no próprio arquivo com `CUIDADO`.
