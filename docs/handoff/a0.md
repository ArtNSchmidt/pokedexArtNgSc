## Decisões que tomei e a alternativa que descartei

| Decisão                                                                                                                                                                          | Alternativa descartada e por quê                                                                                                                                             |
| -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Pacotes consumidos via `dist/` com **TypeScript project references** (`tsc -b`); `typecheck` = `tsc -b tsconfig.build.json && tsc -p tsconfig.json` (constrói deps, depois checa tudo incl. testes) | Consumir `src/*.ts` direto via `exports`: o `node dist/main.js` da API precisaria de _type stripping_ do Node em pacotes vizinhos; frágil em Node 22 < 22.18 e acopla o runtime ao TS. |
| Dois tsconfigs por workspace (`tsconfig.json` inclusivo e `noEmit`; `tsconfig.build.json` composite)                                                                              | Um só: ou os testes vão parar em `dist/`, ou o ESLint `projectService` não encontra os testes em projeto nenhum.                                                              |
| TypeScript **5.9.3**, ESLint **10**, Vite **7** + `@vitejs/plugin-react` **5**, Vitest **4**                                                                                     | TS 7 (fora do `peer` do typescript-eslint, `<6.1`), `@vitejs/plugin-react` 6 (exige Vite 8/rolldown); ESLint 9 está marcado como _deprecated_ no registro.                     |
| `pnpm dev` = `pnpm --filter "./packages/**" build && pnpm -r --parallel dev`                                                                                                     | `--parallel` puro: `tsx watch` da API subiria antes de existir `dist/` dos pacotes.                                                                                            |
| `allowBuilds: { esbuild: true }` e `minimumReleaseAgeExclude` no `pnpm-workspace.yaml`                                                                                            | Gerados pelo pnpm 11 (política de idade mínima de release e aprovação de scripts de build); sem eles o `esbuild` não instala o binário.                                       |
| `.nvmrc` = 22 e `engines.node >= 22`; a máquina de desenvolvimento usa Node 24.16                                                                                                | Fixar 24: o `AGENTS.md` pede 22 e o CI roda em 22.                                                                                                                             |
